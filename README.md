# lp-lab

Competitor landing page teardowns rebuilt on the Graymatter brand system. Static, local, no deploy.

```bash
python3 -m http.server 8787 --bind 127.0.0.1
```

Then open http://127.0.0.1:8787/pages/partner-athlete/ for the Magic Mind athlete-partner mirror.

Read `SPEC.md` for the workflow and brand rules, `deconstructions/` for teardowns, `src/brand/` for
tokens and components. Anything wrapped in a dashed pink chip on a page is a placeholder that still
needs an owner.
