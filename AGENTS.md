# AGENTS.md for lp-lab

Read `SPEC.md` first, then `tasks/sessions.md` for where the last session stopped.

Rules that override defaults in this repo:

- Tokens come from `src/brand/tokens.css` only. Do not hardcode a hex or a font name in
  a page. If a token is missing, add it to tokens.css with a comment citing the Notion
  source, then use it.
- Never copy competitor copy. Structure and mechanics are fair game, words are not.
- Never invent a number, a quote, a credential, or a bio. If it is not in Shopify,
  Notion, or the live site, render a `.todo-chip` and say what is missing.
- Any structure/function claim gets an asterisk and the page keeps the boxed disclaimer.
- Preview with the `lp-lab` launch config, never an ad hoc server.
- Sentence case, no em dashes, no exclamation marks, Graymatter is one word.
- Bright Mind appears on legacy packaging photography. That is unavoidable in imagery.
  It must not appear in text. Flag it in the teardown when the source has it.
